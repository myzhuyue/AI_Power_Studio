## Overview

This introduction outlines the purpose of the Microsoft Power BI training and what topics will be covered. It also provides the expected outcomes and any prerequisites to help you prepare.

## Agenda

This training will cover four parts:

1. Data Cleansing & Transformation
2. Data Modeling
3. Create Measures with DAX
4. Data Visualization

## Learning Objectives

- Understand the Power BI workflow from data to insights.
- Apply data cleansing and transformation techniques with Power Query.
- Design star-schema data models and relationships.
- Author robust measures using DAX for analysis.
- Build effective, accessible, and performant visualizations.

## Prerequisites

- Basic familiarity with data in spreadsheets or CSV files.
- Comfortable using Windows and installing desktop applications.
- Optional but helpful: prior exposure to Excel formulas or pivot tables.

## Tools and Setup

- Power BI Desktop installed (current release).
- Access to sample datasets provided with the course materials.
- A Microsoft account for Power BI Service (optional for publishing demos).

## Course Materials

All slides, sample datasets, and PBIX examples are provided with the training resources. Keep them handy as you progress through each part.

## Next Steps

Proceed to Part 1: Data Cleansing & Transformation.

## Schedule

This section outlines clear, time-boxed training options with milestones. Choose the track that fits your availability, or mix and match.

### Standard Track (4 Weeks)
- Week 1 (6–8 hrs): Power Query basics; data profiling; cleansing; applied steps; merge/append; parameters.
- Week 2 (6–8 hrs): Star schema; relationships; cardinality; role-playing dimensions; calculation tables; date table.
- Week 3 (6–8 hrs): DAX foundations (row vs. filter context); CALCULATE; time intelligence; measures vs. columns; validation.
- Week 4 (6–8 hrs): Visualization best practices; bookmarks; tooltips; drill; performance tuning; publishing & sharing.
- Deliverables: Weekly mini-labs; end-of-track capstone PBIX.

### Accelerated Track (2 Weeks)
- Week 1 (12–15 hrs): Power Query + Modeling combined; build star schema from raw files; create calendar; modeling best practices.
- Week 2 (12–15 hrs): DAX + Visualization; KPIs; YoY/MoM; multi-page report; publish to service; sharing basics.
- Deliverables: Midpoint checkpoint; final presentation & handover.

### Intensive Bootcamp (3 Days)
- Day 1 (8 hrs): Power BI workflow; Power Query deep-dive; ingestion patterns.
- Day 2 (8 hrs): Dimensional modeling; relationships; core DAX patterns.
- Day 3 (8 hrs): Visual design; interactions; performance; deployment.
- Deliverable: One coherent PBIX using provided datasets.

### Prework (Before You Start)
- Install Power BI Desktop (current release).
- Confirm access to sample datasets provided with the course.
- Optional: Microsoft account for Power BI Service (for publishing demos).
- Nice-to-have: Familiarity with Excel formulas or pivot tables.

### Milestones & Assessments
- End of each module: 10–15 minute knowledge check.
- Weekly (or daily for bootcamp) mini-labs aligned to the module.
- Capstone rubric: model quality, measure correctness, usability, and performance.

### Suggested Cadence
- Standard: 2 × 90-minute live sessions/week + 2–4 hrs lab.
- Accelerated: 4 × 90-minute live sessions/week + 4–6 hrs lab.
- Bootcamp: 3 full days; office hours at end of each day.

> Total time budgets: Standard ~24–32 hrs; Accelerated ~24–30 hrs; Bootcamp 24 hrs.

### 30-Day Learning Curve (Daily Plan)
Each day targets 45–90 minutes. Review days (7, 14, 21, 30) consolidate learning.

- Day 1: Orientation; install/verify Desktop; tour of interface; load sample.
- Day 2: Data connections; Import vs DirectQuery; files/databases/cloud sources.
- Day 3: Power Query basics; profiling; types; applied steps; errors.
- Day 4: Transformations: split/merge, pivot/unpivot, fill, replace values.
- Day 5: Combine queries: Merge vs Append; parameters; query groups.
- Day 6: Source patterns: folder ingestion; incremental refresh concepts (theory).
- Day 7: Data quality checklist; mini-lab cleansing challenge (deliverable).

- Day 8: Modeling fundamentals: star schema; fact vs dimension.
- Day 9: Relationships: cardinality; single/bidirectional; active/inactive.
- Day 10: Date table: generate calendar; mark as date table; time cols.
- Day 11: Role-playing dimensions; calculation tables; snowflake cautions.
- Day 12: Model performance basics: cardinality, encoding, summarization.
- Day 13: Mini-lab: build a small star schema from raw files (deliverable).
- Day 14: Checkpoint: review anti-patterns; tidy model; document assumptions.

- Day 15: DAX 101: row vs filter context; VAR/RETURN; evaluation order.
- Day 16: CALCULATE; filter modifiers: ALL/ALLEXCEPT/REMOVEFILTERS; KEEPFILTERS.
- Day 17: Aggregations: SUMX/AVERAGEX; conditional measures; DISTINCTCOUNT.
- Day 18: Time intelligence: YTD/YoY/MoM; DATEADD; SAMEPERIODLASTYEAR.
- Day 19: Semi-additive patterns: opening/closing balance; snapshots.
- Day 20: Validation: control totals; debugging with tables; unit tests for measures.
- Day 21: Mini-lab: author core KPIs; document definitions (deliverable).

- Day 22: Visualization principles: chart choice; layout grid; accessibility.
- Day 23: Interactions: cross-filtering; drillthrough; tooltips; bookmarks.
- Day 24: Advanced visuals: small multiples; field parameters; slicers.
- Day 25: Performance: Performance Analyzer; visual density; aggregations.
- Day 26: Publishing: workspaces; datasets; apps; deployment pipelines overview.
- Day 27: Sharing/governance: certified datasets; permissions; sensitivity labels.
- Day 28: Capstone build: assemble end-to-end report (deliverable).
- Day 29: Polish & QA: usability; mobile layout; accessibility checks.
- Day 30: Present capstone; retrospective; handoff and next steps.
