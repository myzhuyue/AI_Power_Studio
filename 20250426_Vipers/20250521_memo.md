## New Measures are added

1. Manpower In the Door

``` sql
mp_in_door = CALCULATE(SUM(manpower[Structures (In the Door)]))
```

2. Manpower On the Floor

``` sql
mp_on_floor = CALCULATE(SUM(manpower[Structures (On the Floor) ]))
```

3. Production rate% = SUM( Actual + NCO Closed) / Staff on Floor

``` sql
production_rate% = 
var a = [actuals] + [nco_closed]
var b = [mp_on_floor]
return DIVIDE(a, b)
```

4. Combined Actual (From combine file)

``` sql
combo_actuals = 
var a = CALCULATE(sum(scorecard_combined[value]), FILTER(scorecard_combined, scorecard_combined[kpi] = "Actuals"))
return IF(ISBLANK(a), 0, a)
```

5. NCO Age

``` sql
NCO_Ages = DATEDIFF(vipers[Act. Start], vipers[Act. Finish], DAY)
```
