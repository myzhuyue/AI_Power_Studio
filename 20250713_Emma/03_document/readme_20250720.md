1. 新品计算

- Create new column **is_new_product** in Fact_Sales table
```sql
is_new_product = 
SWITCH(TRUE(),
Fact_Sales[Model] IN {"W85845","085438","085516","085525","085727","085728","085729","085730","085731","085732","085739","085740","085788","085800","085816","085821","085822","085823","085824","085830","085846","085860"}, "Yes", // set new product value as Yes
"No" // set existing product value as No
)
```

- Create new measure **New_Product_Sales** in Measurement table
```sql
New_Product_Sales = 
var a = CALCULATE([Sales], FILTER(Fact_Sales, Fact_Sales[is_new_product] = "Yes"))
return IF(ISBLANK(a), 0, a)
```
- Create new measure **New_Product_Sales_LY** in Measurement table
```sql
New_Product_Sales_LY = 
var a = CALCULATE([New_Product_Sales], DATEADD(Dim_Calendar[Date], -1, YEAR))
return IF(ISBLANK(a), 0, a)
```
- Create new measure **New_Product_Sales_YoY%** in Measurement table
```sql
New_Product_Sales_YoY% = 
var a = [New_Product_Sales] - [New_Product_Sales_LY]
return DIVIDE(a, [New_Product_Sales_LY])
```
